**Project Overview**

This project analyzes ride booking data from an Ola (Ola Cabs). The goal is to understand booking trends, revenue performance, cancellation rates, and customer behavior using data analysis tools like Excel and Power BI.
An interactive dashboard was created to help visualize key metrics and provide actionable business insights.

**Objectives**

Analyze total bookings and ride completion rate
Identify peak booking hours and demand patterns
Calculate total revenue and revenue by vehicle type
Analyze cancellation trends
Evaluate vehicle performance
Create an interactive dashboard

**Tools & Technologies Used**

Microsoft Excel (Data Cleaning, Pivot Tables)
Power BI (Dashboard, Data Visualization)

**Key KPIs**

Total Bookings
Completed Rides
Cancelled Rides
Cancellation Rate
Total Revenue
Average Ride Distance
Revenue by Vehicle Type

 **Dashboard Features**

KPI Cards (Total Bookings, Revenue, Cancellation Rate)

Bar Chart (Revenue by Vehicle Type)

Line Chart (Booking Trends)

Pie Chart (Ride Status Distribution)

Interactive Filters and Slicers
